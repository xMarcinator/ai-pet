# fn-2-layered-sprite-and-vector-pets.2 Bake Sprout and Hood into layered packs, switch the pet to the compositor, remove the procedural renderer

## Description
The early proof point. A bake step runs today's renderer for every channel value and writes Sprout and Hood as layered pixel packs (manifest + PNG sheets). They are embedded with `include_bytes!`, and `Pet` composites them into the existing body/glow/fx layer buffers, so the UI is unchanged. Then the procedural drawing (`Pet::draw`, the cell tables, the avatar rasteriser) is deleted. The frozen `frames.json` goldens now pin the composited output within the spec's tolerance.

**Size:** M
**Files:** `rust/crates/aipet-sprite/src/bin/bake.rs` or `tests/bake.rs` (new, bake step), `rust/crates/aipet-sprite/packs/{sprout,hood}/**` (new, generated), `rust/crates/aipet-sprite/src/pet.rs`, `rust/crates/aipet-sprite/src/avatar.rs`, `rust/crates/aipet-sprite/tests/golden.rs`, `rust/crates/aipet-sprite/Cargo.toml`, `rust/Cargo.toml`
**Touches:** [rust/crates/aipet-sprite/**, rust/Cargo.toml, rust/Cargo.lock]

### Approach
- Bake before deleting: one commit adds the bake and the generated packs, the next switches `Pet` to the compositor, the last deletes the renderer. Each commit keeps the goldens green, within the tolerance from the switch on.
- Layer split to try first: body (silhouette + shading + face panel), eyes, arms, feet, prop, headphones, fx, glow. If outline cells where arms and feet meet the body break the tolerance, bake arms and feet into body per pose (spec: Early proof point).
- PNG encode and decode: add the `png` crate (or `image` with only `png`) to the workspace dependencies. Decoding is also needed at runtime.
- Make the bake reproducible: a test re-runs it into a temp dir and diffs it against the committed packs, run before the renderer is deleted. After deletion, keep the golden comparison as the pin.
- Keep `PetFrame`'s three buffers for now so `aipet-ui` needs no change in this task.
