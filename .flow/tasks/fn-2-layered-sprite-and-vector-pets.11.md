# fn-2-layered-sprite-and-vector-pets.11 Native .aseprite files and grid sprite sheets in packs

## Description
Let raster packs carry pixel art straight from Aseprite (the native `.aseprite` file) and plain grid sprite sheets, alongside task 3's explicit frames and Aseprite `json-array` exports (spec: API Contracts → Native Aseprite files, Grid sprite sheets; R20). All three forms produce the same in-memory layers, animations, parts and pivots, so everything after loading is unchanged.

**Size:** M
**Files:** `rust/crates/aipet-sprite/src/aseprite.rs`, `rust/crates/aipet-sprite/src/load.rs`, `rust/crates/aipet-sprite/Cargo.toml`, `rust/Cargo.toml`, `rust/crates/aipet-sprite/tests/**`, `avatars/samples/**` (new: a small native-Aseprite sample and a grid-sheet sample)
**Touches:** [rust/crates/aipet-sprite/**, rust/Cargo.toml, rust/Cargo.lock, avatars/samples/**]

### Approach
- Native files: read the format directly, starting from the spike's `rust/spikes/aseprite/src/reader.rs` on `spike/aseprite` (about 200 lines, `flate2` only). Don't use `asefile` (proof: `rust/proofs/aseprite.md`):
  - 0.3.8 adds a second `image`;
  - it rejects ping-pong reverse tags, embedded ICC profiles and unknown chunks;
  - it aborts on a cel claiming 65535×65535;
  - it inflates zlib bombs without a bound;
  - it decodes everything in one call, so the 64 MB limit can't be enforced.

  Subset: frames, layers (normal, group), cels (raw, linked, zlib), RGBA, greyscale and indexed, tags (all four directions, repeat), slices (keys, pivots), palettes 0x2019, else 0x0004. Skip unknown chunks.
- Map the native file like the export (task 3):
  - tags `<layer>:<key>` become animations;
  - direction gives the frame order and loop mode, and a repeat count n is unrolled n times and then `once`;
  - frame durations as given;
  - a part slice's frame-0 key, origin plus pivot, gives the part's origin (R18);
  - the part's frames are the layer cropped to the slice, with the slice's pivot;
  - the slice key at a tag's first frame gives the pose position;
  - whole-layer frames are cropped to the opaque box, with pivot = anchor − crop origin.
- Reject tilemap layers, tilesets, external files, unknown colour depths and malformed tags. Check limits before allocating:
  - file ≤ 8 MB;
  - canvas side ≤ 2048 and frames ≤ 512, from the header;
  - layers ≤ 16;
  - each cel's `w × h × bpp` charged against the 64 MB budget before inflating;
  - inflate bounded to the stated size, and an error if the data is longer or shorter.
- Grid sheets: a frame index becomes a rectangle by `origin + (i % columns, i / columns) * (frame + gap)`; `ms` is a number or a list. Reuse task 3's frame type, so nothing downstream knows the difference. Also reject `columns ≤ 0`, a negative origin, gap or index, and use checked arithmetic.
- `--check-pack` reports native and grid packs like the others.

### Testing without Aseprite (it's paid)
- Fixtures are generated by the tests with a test-only writer for the documented subset, starting from the spike's `src/writer.rs` (about 130 lines, `flate2` only). It covers the header, frames, palette, layers (with groups and UUIDs), cels (raw, linked, zlib), tags with user data, and slices with pivots, in RGBA and indexed. It also generates the error cases: ping-pong reverse, repeat counts, an unknown chunk, a zlib bomb, an oversized cel and an oversized canvas. The matching `json-array` exports are written by hand. CI never runs Aseprite.
- Real-editor files: a subset of the `asefile` repo's `tests/data/*.aseprite`. They are MIT (Copyright (c) 2020 Alpine Alpaca Games), so record that in THIRD-PARTY-NOTICES. Use them with their reference PNGs, e.g. `indexed`, `linked_cels`, `layers_and_tags`, `slice_advanced`, `grayscale`, `256_color_old_palette_chunk`, and `tilemap` as the reject case. Add one LibreSprite file if the user approves the download.
- Optional: one file made in a real Aseprite by the user, if they have it, checked in the hands-on task (8). Nothing depends on it.

## Key context
Aseprite stores `repeat` as a count in the file but as a string in the JSON export; normalise both into the same loop model. A ping-pong count counts each direction. Aseprite 1.3 adds ping-pong reverse (direction 3), layer UUIDs (header flag 4) and cel z-index; read the first two, and ignore z-index. The spike didn't decide how hidden and reference layers are treated, or cover group opacity and non-normal blend modes: decide them here.
