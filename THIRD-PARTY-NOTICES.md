AiPet itself is released under the MIT License (see [LICENSE](LICENSE)).

The release packages contain two programs, the pet (`AiPet`, `AiPet.exe`) and `aipet-hook`, the program the Claude
Code and Codex plugin runs. Both are written in Rust and built from the crates listed below, which are compiled into
them. The Windows installer also carries Velopack's `Setup.exe` and `Update.exe`:

| Component | Version | What it's for | License | Copyright |
|---|---|---|---|---|

Velopack's `Setup.exe` and `Update.exe` are written in Rust and built from crates that carry their own licenses.

The pet draws its text in the system's own fonts (Segoe UI on Windows, Noto Sans on Linux), which aren't part of
AiPet. The one font compiled into it is iced's small icon font (`Iced-Icons.ttf`, made with Fontello), which is part
of the `iced_graphics` crate and comes under that crate's license below.

The Aseprite files in `rust/crates/aipet-sprite/tests/fixtures/asefile/` (MIT, Copyright (c) 2020 Alpine Alpaca
Games) are test data only: nothing of them is built into AiPet. Their license is beside them.

pub fn escape(text: &str) -> String {
    let mut quoted = String::new();
    escape_into(text, &mut quoted);
    quoted
}

fn escape_into(text: &str, buf: &mut String) {
    buf.reserve(text.len());
    for c in text.chars() {
        if is_meta_character(c) {
            buf.push('\\');
        }
        buf.push(c);
    }
}

fn is_meta_character(c: char) -> bool {
    match c {
        '\\' | '.' | '+' | '*' | '?' | '(' | ')' | '|' | '[' | ']' | '{' | '}' | '^' | '$'
        | '#' | '&' | '-' | '~' => true,
        _ => false,
    }
}
